# postset - capstone

PostSet: a shared clip library for festival and concert crowds, sorted by song. IST300 capstone.

## Run it locally

Needs Python 3 (already on macOS). From the repo root:

```
python3 -m http.server 8000 --directory src
```

Then open http://localhost:8000 in a browser.

The screens in `src/` started as the Lab 4 prototype (`docs/design/prototype/`). They are being turned into working screens one story at a time.
